# MAA 明日方舟（`maa_*` 工具）

插件：`@local/dsh-maa`（bundle 目录 `plugins\maa-plugin`；装进 profile 后在 `node_modules` 里，设置页在 **设置 → 插件 → 「MAA 助手」**）。**不要**用 adb 点击或浏览器截图替代；协议里查不到理智/仓库/关卡，别编数字。

## 每次动手前（顺序别跳）

0. 模拟器 + 进游戏：插件加载时**已自动**查过 MuMu 开没开，没开就拉起来并等到能连。
   - 之后要进主界面，直接 `maa_wakeup()` —— 它复用 MAA「一键长草」里的**开始唤醒**（`LinkStart-WakeUp`），实测**可以单独下发**、约 60~110 秒到主界面；**不要自己截图去找「开始唤醒」按钮或点公告**。不消耗理智。
   - 工具仍报连不上/`adb devices` 没设备时再 `maa_emulator({action:"start"})`，**不要**自己拼 MuMuManager 命令。
   - **模拟器偶发闪退/掉线是已知偶发问题**（未定位、不常复现）：直接 `maa_emulator({action:"start"})` 重启即可，不必深挖；**连续反复出现**才值得排查（看 MuMu 日志、内存/驱动）。
1. `maa_health`：`online=false` = MAA 没开或「远程控制」端点没配 → 如实告诉用户，**不要重试、不要换方案瞎试**。
2. 第一次用 / 任何异常 → `maa_doctor`：看 `problems`（必修为空）、MAA 版本、能力表、练度解析（N 行 / 拥有 M）、adb 设备。
3. 抄作业前：游戏必须停在**目标关卡的详情页或编队页**（Copilot 不会导航；到不了就用 `maa_swipe` 自己滑过去），**代理指挥必须关**（开着会锁死队伍）。
4. 滑动前确认没有 MAA 任务在跑（有任务时 `maa_swipe` 会拒绝）；滑动起点必须落在空白处，压在按钮上会真的点进去。
5. **换人/新用户**：先确认现在登录的是不是**请求者本人**的号（`maa_screenshot` 看主界面左上角医生名）。对不上就按下面「多用户：换号 / 新用户登录」处理——**动任何登录/切号动作前先跟用户说「我已经在做了」**。

## 多用户：换号 / 新用户登录（v2.1.0）

一台电脑可能被多个用户用。当前登录的不是请求者的号时，**先换号再干活**；对方从没在这台电脑登过明日方舟（或登录过期）就走新用户登录。

**账号簿只存「掩码登录名」**（官服 = 前三后四位，如 `173****8245`）：MAA 的账号切换是按游戏登录页显示的名字做 OCR 匹配的，**完整手机号匹配不上**；传完整 11 位号给 `register` 会自动转成掩码，本地不留完整号。要发验证码登录时**向用户要完整手机号**（账号簿里取不到）。

**开场**：动登录/切号前先回用户一句「**我已经在做了**」，再开始。**任务随时可取消**：用户说停就停；后台切换用 `maa_copilot_stop(runId)` 停，然后截图告诉用户停在哪一屏。

### 流程

1. 问用户：**账号绑定的手机号** + **明日方舟账号昵称**（主界面左上角医生名）。
2. `maa_account_book({action:"find", phone, nickname})`：
   - `registered:true` → 老用户，走**逻辑2**；
   - `registered:false` → 先问「要不要把这个号注册到本地账号簿」；同意后 `maa_account_book({action:"register", phone, nickname})`（只存本地 `data/accounts.json`，入库自动转掩码登录名）。
3. 再问**登录方式**：手机号 + 验证码，还是扫码。
4. **占用检查**：`maa_current()`——`running` 非空说明别人正在用 → **请请求者稍等，不要 maa_stop 别人的任务**；空闲才继续。要更细的「闲不闲/连续状态」用 `maa_task_state()`（只读，含 `running/taskType/sequence`；**MAA 界面里手点的任务看不到**）。
5. 模拟器：`maa_emulator({action:"status"})`。没开 → `maa_emulator({action:"start"})`，然后按**逻辑1**；已经开着 → 先试**逻辑2**。

### 逻辑2：切换到登录过的账号（MAA 账号切换）

1. 游戏在线时，先做**账号退出逻辑**，把游戏退到「开始唤醒」界面：
   - 不在首页：点**左上角从左往右第二个控件** → 弹出跳转面板 → 点「**首页**」回首页。
   - 已在首页：点**左上角齿轮**（参考 1280 系 ≈ `(47,40)`）→ 设置页左下角「**账号登出**」（参考 ≈ `(73,647)`）→ 点右边**红底白字的确认勾**（以截图为准）→ 回到「开始唤醒」界面。
2. `maa_account_switch({phone:"<掩码登录名>", background:true})` → 拿 `runId`；`maa_copilot_status(runId)` 盯进度 + `maa_screenshot` 看画面。
3. 截图确认**主界面左上角医生名 = 目标昵称** → `maa_account_book({action:"touch", phone:"<掩码>", loginMethod:"switch"})` → 告诉用户当前账号昵称 → 问这次要做什么。
4. **失败/登录过期**（`advice.verdict` = `switch-unavailable` / `switch-failed` / `timeout`）→ 当新用户走**逻辑1**；最多重试一次，不要重试到死。若是 **`switch-probably-succeeded`**（回调里看到账号切换、但任务链最后报 FAILED，实测 MAA 切完会继续唤醒触发 ExceededLimit）：**先截图核对医生名**——是目标账号就按成功处理（touch 记录、继续办事），不要让人重新登录。

### 逻辑1：新用户登录（没有登录记录 / 登录过期）

起点是「开始唤醒」界面（刚启动的 MuMu 会停在游戏标题页：**点任意位置**进来）。界面底栏 = 扫码登录 / 账号管理 / 查看公告 / 设置（1280 系 y≈682）。

1. 点底栏「**账号管理**」（≈ `(783,682)`，以截图为准）→ 弹窗里点「**登录其他账号**」（≈ `(640,497)`）。
2. 按选定方式登录：
   - **手机号 + 验证码**（顺序别错）：点「请输入手机号」（≈ `(640,285)`）→ `maa_input_text({text:手机号})` → **先勾选隐私政策圆形按钮**（在「注册/登录」按钮上方第一行文字的左边，≈ `(450,448)`）→ 点「**获取验证码**」（≈ `(753,367)`）→ **立刻问用户要验证码**（拿到马上输，不要存）→ 点验证码框（≈ `(640,367)`）→ `maa_input_text({text:验证码})` → 点「**注册/登录**」（≈ `(640,513)`）。**注意：不先勾协议，点「获取验证码」不会发码（或点了没反应）——这就是以前的 bug。**
   - **扫码**：点手机号输入框**右上角二维码图标**（≈ `(868,240)`）→ 出现登录二维码 → **马上截图发给用户**（回复里用 `![扫码登录](<绝对路径>)`；发完结束本轮等用户扫）→ 用户说过期就点**二维码中央**（≈ `(640,383)`）刷新再截图。标题页底栏也有「**扫码登录**」（≈ `(608,682)`），只扫码时直接点它更省两步。二维码会过期，动作要快。
3. 登录成功后：截图看主界面左上角医生名 → **告诉用户当前账号昵称** → `maa_account_book({action:"touch", phone, loginMethod:"code"|"qr"})` → 问用户这次的目标。
4. 卡住/失败：截图确认停在哪一屏，如实告诉用户；不要连续盲点。**关掉账号管理弹窗（X ≈ `(851,200)`）会弹「登录被取消，请重试」+ 白色 ✓（≈ `(640,491)`）——点掉 ✓ 才回标题页。**

### 隐私与安全（不是建议，是规矩）

- 验证码只在当轮用：**不落盘、不写日志、不发到任何外部服务**；账号簿只存**掩码登录名**（前三后四位），本地不留完整手机号，`list` 一律打码。**不要把别人的账号情况告诉其他用户**。
- 二维码截图只发给当前请求者本人（展示在会话里），不要转发。
- 登录/切换中途别 `maa_run` 起别的任务；失败先截图找原因，再决定重试还是转逻辑1。

## 怎么走到目标关卡（首次必读；Copilot 不做导航）

`maa_copilot_run` 要求游戏**已经停在目标关卡的详情页/编队页**。按这张表走，不要瞎点：

| 要找什么 | 怎么走 |
|---|---|
| 主线关卡 | 终端 → **曲谱** → **乐章收录** → 章节选择列表（**上下滑动**挑章节，右下角 `EPxx` = 第 xx 章）→ 点进章节 → **在地图内左右滑动**找关卡 → 点关卡节点 → 详情页 |
| 往期活动 | 同一个章节列表里，活动章节一般排在**所有主线章节下方**，封面用**艺术字**写活动名 → 点封面进活动 → 活动页右下角通常有 2~3 个按钮切**普通关 / EX 关 / 特殊关** |
| 当期活动 | **终端页面左侧**的活动海报（同样艺术字标名）→ 点进去即可。活动结束会显示「**作战已结束**」，其余逻辑与往期活动相同 |
| H 关（主线高难） | 关卡选择界面有**难度切换**：切到**最高难度**（如「磨难」）后 H 关才出现在**地图最右侧**（如 12 章 → H12-1/2/3/4），再用 `maa_swipe` 滑到最右端 |

不熟悉当前在哪一屏 → 先 `maa_screenshot`（1280×720 坐标）再按坐标 `maa_click` / `maa_swipe`；滑动起点选空白处，别压在按钮或关卡节点上。

| 点掉游戏弹窗 | `maa_click({x,y})`（**1280×720** 坐标，独立核心会话） |
| 走到要滑动的关卡 / 列表翻页 | `maa_swipe({from,to})`（**1280×720**，起点选空白，不消耗理智） |

| 换人 / 登录别人的号 | `maa_account_book`（查/登记）→ 逻辑2 `maa_account_switch({phone:"<掩码>"})`；逻辑1 按上面「多用户」一节走 |
| 查 MAA 现在忙不忙 / 等它跑完 | `maa_task_state()`（只读；`waitMs` 可等下一次状态变化，最多 55s；只覆盖插件下发的任务） |

| 自检 / 路径不对 / 练度没解析出来 | `maa_doctor` |

## 怎么自定义刷关 / 识别（v2.2.0）

1. **先 dryRun**：`maa_chain({tasks:[...], dryRun:true})` 只 append 校验参数（不连接、不 startTask、不消耗）；返回的 appended 都拿到 taskId 后再去掉 dryRun。
2. **Fight 先问用户**（消耗理智）：只刷 1-7 三次不吃药 = `[{type:"Fight",params:{stage:"1-7",times:3,medicine:0,stone:0}}]`；只跑基建+公招 = `Infrast` + `Recruit`；领奖+刷关 = `Award` → `Fight`。`StartUp` 会切号/登游戏、`CloseDown` 会关游戏，同样先问。
3. **长链后台跑**：`background:true` 拿 runId → `maa_copilot_status/stop` 盯/停；Fight 掉血立刻 stop，再自己点「暂停 → 退出行动」（结算前退全退理智）。
4. **识别**：干员 `maa_toolbox({action:"operbox"})`（实测约 30s；`total/ownedCount` + 前 50 条，完整在 `dumpFile`）；仓库 `depot`；视频 `video` + `file`（纯本地、不用模拟器；产出 `jobFile` 可直接抄）；抽卡 `gacha` + `times`（**先问用户**）。
5. **别手改 `gui.new.json`**：临时编排用 `maa_chain`；永久改 MAA 一键长草队列/关卡在 MAA GUI 里改（MAA 运行时会覆盖手改）。

## 长任务节奏

`maa_run` 只拿 `taskId`，不阻塞；`maa_wait` 每次 ≤55s 循环；每 3–5 轮插一张 `maa_screenshot` 确认没卡在登录/弹窗。`LinkStart` 整轮可能 30–60 分钟；`pending` / `lost` 都**不等于**失败。

## 抄作业（防非三星版；**生命值守则优先级最高**）

0. 前置：模拟器在跑、游戏停在目标关卡详情页/编队页、**代理指挥关**；`maa_doctor` 四项都对（MAA 版本 / 练度解析 / adb 设备 / 无 problems）。
1. `maa_copilot_find({stage})` → 先看 `matchMode`（`strict` = 有完全达标的作业，首选；`relaxed` = 全是放宽出来的），取 `jobs[]` 里 `views` 最高的一条的 `file`。
2. `maa_copilot_run({file, dryRun:true})` 零消耗验证 core 能解析。
3. `maa_copilot_run({file, background:true})` 真跑（**真实理智，跑前先问用户**）→ 拿到 `runId`。
4. **盯生命值（不能省）**：每约 10 秒 `maa_copilot_status()` 看进度 + `maa_screenshot` 后 `read_image` 看画面。重点是**目标生命值**：一旦掉血（生命值右侧出现红色负值 / 生命图标变红），马上进第 5 步。
5. **掉血立刻止损**：`maa_copilot_stop()` 停掉 MAA 任务 → `maa_screenshot` 看画面 → `maa_click` 点「暂停」→ 点「退出行动」→ 确认。**结算前退出关卡会返还全部理智**；掉过血还打到底 = 花了理智还拿不满奖励。
6. 换下一条作业重来（**同一条不重跑**）。如果所有作业都掉血/都失败 → 如实告诉用户：**没有能三星通关的作业**。
7. 正常跑完后 `maa_screenshot` + `read_image` 确认三星；`maa_copilot_status().result.advice` 是给用户的口径，照它说。
8. **结算页怎么出来**：一关打完后**直接点画面空白处**就回到关卡选择界面了。右上角弹出的「可以使用代理指挥了 / 是否应用新的代理指挥阵容」**不用管、不用点**，无视它直接点空白处即可（别去点 ✓，会把作业阵容写成代理指挥阵容）。然后接着下一关或收尾，不用停在这个页面上等确认。

**收尾**：所有目标都完成后，**直接把结果汇报给用户并收尾**（打到什么、三星没有、花了多少理智、还剩什么没做）；不要反复请示、不要为了"再确认一下"继续点。

**练度口径（用户定，不许自行放宽）**：**先找完全达标的作业**；只有当这一关**所有候选都做不到完全达标**时，才按容差放宽（专精要求按 7 级技能代替；精二等级下浮 30 但不低于 60；模组原样交给 MAA 复验）。`matchMode` 说明用了哪一档，`relaxedBecause` 写明差在哪。**练度不够就换作业，不要提示提升练度**。

**失败口径**：**放宽档作业跑失败 → 直接告诉用户「没有找到这个账号可以抄的作业」**（不重试、不建议提升练度）；严格档失败才换下一条。这条 sidecar 会带到 `maa_copilot_run` 的 `advice` 里，照它说。练度文件路径在 **设置 → 插件 → 「MAA 助手」** 里改。

## 验收（`SUCCESS` / `ok` 都不算数）

至少看两样：`debug\gui.log` 的 `开始任务:` / `完成任务:` 行（最硬）；`maa_screenshot` 有真实游戏画面；抄作业额外看三星截图。

## 禁则

- 抽卡 / 碎石 / 吃药 / `StopTask` 打断正在跑的长草 → **先征得用户同意**。
- `maa_chain` 里的 Fight / StartUp / CloseDown 有真实代价（理智 / 切号 / 关游戏）→ **先问用户**；链失败/超时不要自动重发 Fight。
- 一次只排一个长任务；**同一个 `LinkStart` 绝不重发**（会抢占、从头重开）。
- 任务跑着时 `maa_set` 会排在它后面，别以为立刻生效。
- 抄作业：**不许起跑后不管生命值**（阻塞模式只用于已验证过的作业）；掉血必须立刻退，别赌能三星。
- 抄作业失败换下一条，**不重试同一条**；放宽档失败就下「没有可抄作业」的结论。
- 登录/换号：动任何登录动作前**先说「我已经在做了」**；验证码**不落盘、不外发**；不把别人的手机号/账号告诉其他用户；切号失败最多重试一次，别把过期账号当 bug 反复试。
